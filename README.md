# سیناپس

آزمایشگاه مطالعه نورولوژی برای ۲۳ فصل درسنامه بیماری‌های مغز و اعصاب (کمیته علمی انجمن مغز و اعصاب ایران، ویراست دوم).

دفتر مطالعه صفحه به صفحه است: هر صفحه هدف، درس، حاشیه امتحان و یک سؤال دارد و تا جواب ندهی صفحه بعد باز نمی‌شود. صفحه‌های غلط جدا علامت می‌خورند. کنارش فلش‌کارت، کیس و آزمون همان فصل‌ها هست.

این مخزن **متن کتاب را بازنشر نمی‌کند**. محتوا بازنویسی آموزشی مستقل است و جای پروتکل درمانی یا کلید آزمون نیست.

کنار همان ۲۳ فصل، یک مسیر جدا به نام «صد صفحهٔ اول روش بالینی» هست: شرح حال، معاینه، بررسی آزمایشگاهی، کما و شروع حالات کنفوزیونی. این مسیر هم بازنویسی مستقل است و متن هیچ کتاب مرجعی را بازنشر نمی‌کند.

## اجرا

```bash
npm install
npm run dev
```

## انتشار

ساخت پروژه برای خروجی سرور (Nitro / Vercel) تنظیم شده است:

```bash
npm run build
```

اگر بخواهی همین ریپو را به Netlify وصل کنی، در `vite.config.ts` مقدار `preset` نیترو را از `vercel` به `netlify` عوض کن و دوباره بیلد بگیر. تا وقتی پیش‌نمایش همین محیط را می‌خواهی، preset را روی `vercel` بگذار.

# سیناپس

آزمایشگاه مطالعه نورولوژی: درس کوتاه، فلش‌کارت، کیس و آزمون برای ۲۳ سرفصل هم‌راستا با درسنامه بیماری‌های مغز و اعصاب (کمیته علمی انجمن مغز و اعصاب ایران، ویراست دوم).

این مخزن **متن کتاب را بازنشر نمی‌کند**. محتوا بازنویسی آموزشی مستقل است و جای پروتکل درمانی یا کلید آزمون نیست.

## اجرا

```bash
npm install
npm run dev
```

## انتشار

ساخت پروژه برای خروجی سرور (Nitro / Vercel) تنظیم شده است:

```bash
npm run build
```

اگر بخواهی همین ریپو را به Netlify وصل کنی، در `vite.config.ts` مقدار `preset` نیترو را از `vercel` به `netlify` عوض کن و دوباره بیلد بگیر. تا وقتی پیش‌نمایش همین محیط را می‌خواهی، preset را روی `vercel` بگذار.
